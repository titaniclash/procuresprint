Principles

Four rules decide every component and screen.

Every number is a door

A count on a tile filters the list beneath it. If a number cannot be acted on, it moves to Insights.

Work before totals

Landing pages open on what needs the user now: overdue, blocked, ageing. Totals sit second.

Colour means status

Teal is the only brand colour. Every other hue is a status or a chart series, from one fixed table.

One way to do a thing

One table, one assistant, one status chip, one approve flow. Modules compose; they never restyle.

Colour

Three tiers: primitives → semantic tokens → component tokens. Components only read semantic tokens, so light and dark themes switch with no component change.

Contrast ratios on the right are computed live in your browser from the CSS variables. Light is the default theme; dark is opt-in with data-ps-theme="dark" on the root.

Spacing & shape

4 px base on an 8 pt rhythm. Square-ish corners (4–8 px) keep the product reading as a precise tool. Surfaces are separated by 1 px rules, not shadows; shadows are reserved for things that float.

Accessibility

Target: WCAG 2.2 AA. Built into tokens and components; verified on the build in Phase 5, not claimed before.

CriterionHow the system meets it
1.4.3 ContrastAll text tokens ≥ 4.5 : 1 in light and dark; table above is computed live.
1.4.11 Non-text contrastInput borders use --ps-line-strong (≥ 3 : 1); chart series ≥ 3 : 1.
1.4.1 Use of colourStatus chips carry words; risk shows number + bar + word; priority shows icon + word.
1.4.10 ReflowShell collapses at 904 px; tables become card lists under 600 px.
2.4.7 / 2.4.11 Focus2 px teal ring with 2 px offset on every interactive element, never hidden behind sticky bars.
2.5.8 Target sizeInteractive targets ≥ 32 px (icon buttons 40 px); sidebar items 44 px.
2.1.1 KeyboardSkip link, arrow keys in tabs and menus, Esc closes overlays, "/" jumps to search.
3.3.1 / 3.3.3 ErrorsInline message with icon under the field, aria-invalid, and an error summary on submit.
Reduced motionAll durations drop to 0 under prefers-reduced-motion; forced-colours mode respected.
